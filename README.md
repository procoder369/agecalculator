# 📅 Responsive Age Calculator

A responsive, browser-based Age Calculator built with **HTML**, **CSS**, and **JavaScript**, powered by [Luxon](https://moment.github.io/luxon/) for precise date calculations and live birthday countdowns.

## ✨ Features

- 🎂 **Accurate Age Calculation** — Get your exact age in years, months, and days.
- ⏳ **Birthday Countdown** — See exactly how much time is left until your next birthday.
- 📱 **Fully Responsive** — Works seamlessly across desktop, tablet, and mobile devices.
- ⚡ **Powered by Luxon** — Reliable, timezone-aware date/time handling instead of native `Date` quirks.
- 🎨 **Clean, Modern UI** — Simple and intuitive interface for quick results.
