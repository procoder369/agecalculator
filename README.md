# Age Calculator

A responsive, clean age calculator that tells you exactly how long you've been alive — down to the day — and counts down to your next birthday.
<img width="1766" height="857" alt="Screenshot 2026-09-20 123320" src="https://github.com/user-attachments/assets/9d0575d5-f3aa-4904-972f-84138dd9635c" />


## Features

- 📅 Calculate your exact age in **years, months, and days**
- 🎂 See a live countdown to your **next birthday**
- 📱 Fully **responsive** design for desktop and mobile
- ⚡ Accurate date calculations powered by [Luxon](https://moment.github.io/luxon/)
- 🎨 Simple, elegant UI

## Tech Stack

- **HTML** – structure
- **CSS** – styling and responsive layout
- **JavaScript** – logic and interactivity
- **[Luxon](https://www.npmjs.com/package/luxon)** – precise date and time calculations



| Package | Purpose |
|---------|---------|
| [npm](https://www.npmjs.com/) | Package manager used to install project dependencies |
| [luxon](https://www.npmjs.com/package/luxon) | Handles date parsing, age calculation, and birthday countdown logic |
